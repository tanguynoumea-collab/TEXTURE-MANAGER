    **1. Create MaterialEditorViewModel.cs** in ViewModels/ namespace Olympe.MaterialManager.ViewModels:

    A sub-ViewModel (Claude's discretion: separate sub-VM, not inline in RightPanelVM) that manages the material editor section.

    Properties ([ObservableProperty]):
    - string _materialName = string.Empty
    - string _description = string.Empty
    - int _colorArgb
    - byte _colorR, _colorG, _colorB (extracted from ColorArgb for individual TextBox binding)
    - string _patternName = string.Empty
    - bool _hasAppearanceAsset
    - bool _tintEnabled
    - int _tintColorArgb
    - byte _tintR, _tintG, _tintB (extracted from TintColorArgb)
    - bool _isVisible = false (controls section visibility, collapsed when no material selected)
    - string? _thumbnailPath

    Private field: long _currentMaterialIdValue = -1, RevitEventBridge? _eventBridge

    Constructor: MaterialEditorViewModel(RevitEventBridge eventBridge)
    - Store _eventBridge
    - Register for MaterialSelectedMessage via WeakReferenceMessenger.Default.Register<MaterialSelectedMessage>(this, OnMaterialSelected)
    - Register for MaterialEditedMessage to refresh after edits from other sources if needed

    Designer constructor: MaterialEditorViewModel() : this(null!)

    OnMaterialSelected handler:
    - If msg.Value is null: set IsVisible = false, return
    - Store _currentMaterialIdValue = msg.Value.MaterialElementIdValue
    - Call FetchMaterialDetails()

    FetchMaterialDetails():
    - _eventBridge.MakeRequest(RevitRequestType.GetMaterialDetails, _currentMaterialIdValue, callback)
    - In callback: if result is MaterialDetailsDto dto, populate all properties from dto
    - Extract RGB bytes: ColorR = (byte)((dto.ColorArgb >> 16) & 0xFF), ColorG = (byte)((dto.ColorArgb >> 8) & 0xFF), ColorB = (byte)(dto.ColorArgb & 0xFF). Same extraction for TintColorArgb -> TintR/G/B.
    - Set IsVisible = true
    - If result is Exception: set IsVisible = false (graceful handling)

    Edit commands (each per D-03, D-10 -- one Transaction per edit):

    [RelayCommand] EditName():
    - Guard: if _currentMaterialIdValue < 0 || _eventBridge == null, return
    - Create EditMaterialNameRequestDto { MaterialIdValue = _currentMaterialIdValue, NewName = MaterialName }
    - MakeRequest(EditMaterialName, dto, OnEditResult)

    [RelayCommand] EditDescription(): same pattern with EditMaterialDescriptionRequestDto { NewDescription = Description }

    [RelayCommand] EditColor():
    - Create EditMaterialColorRequestDto { MaterialIdValue, Red = ColorR, Green = ColorG, Blue = ColorB }
    - MakeRequest(EditMaterialColor, dto, OnEditResult)

    [RelayCommand] EditTint():
    - Guard: if !HasAppearanceAsset, return
    - Create EditMaterialTintRequestDto { MaterialIdValue, TintEnabled, Red = TintR, Green = TintG, Blue = TintB }
    - MakeRequest(EditMaterialTint, dto, OnEditResult)

    OnEditResult(object? result):
    - If result is Exception: handle gracefully (could set a status message)
    - Else (success): Send MaterialEditedMessage(_currentMaterialIdValue) via WeakReferenceMessenger.Default.Send for preset list refresh (D-21)
    - Then call FetchMaterialDetails() to refresh preview and all fields (D-19, MATEDIT-07)

    partial void OnTintEnabledChanged(bool value):
    - If _currentMaterialIdValue >= 0 and HasAppearanceAsset: call EditTintCommand.Execute(null) to immediately sync toggle state

    - OnMaterialEdited: if any preset in PresetGroups has MaterialElementIdValue matching the edited ID, re-fetch its name. Simple approach: trigger a status update or re-read from MaterialEditorVM.MaterialName.
