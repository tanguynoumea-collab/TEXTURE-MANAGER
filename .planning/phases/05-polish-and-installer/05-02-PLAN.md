**1. Add StageForInstaller MSBuild target to OlympeMaterialManager.csproj** (per D-11):
Read the csproj. Add a Target element at the end of the Project, AFTER all ItemGroup elements. Use the research code example:
```xml
<Target Name="StageForInstaller" AfterTargets="Build"
        Condition="'$(Configuration)' == 'Release'">
  <PropertyGroup>
    <StagingDir>$(SolutionDir)installer\OlympeMaterialManager.Installer\staging</StagingDir>
  </PropertyGroup>
  <ItemGroup>
    <StagingFiles Include="$(OutputPath)**\*.*"
                  Exclude="$(OutputPath)**\*.pdb;$(OutputPath)**\*.xml" />
  </ItemGroup>
  <Copy SourceFiles="@(StagingFiles)"
        DestinationFolder="$(StagingDir)\$(TargetFramework)\%(RecursiveDir)" />
</Target>
```
This copies Release build output (excluding .pdb and .xml) to the installer's staging/ directory, organized by TFM. This runs ONLY in Release configuration so Debug builds are unaffected.
