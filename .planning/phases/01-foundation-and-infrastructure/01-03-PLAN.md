    **2. Create `Models/RevitDocInfoDto.cs`:**
    ```
    namespace Olympe.MaterialManager.Models;
    public class RevitDocInfoDto
    {
        public string Title { get; set; } = string.Empty;
        public string PathName { get; set; } = string.Empty;
        public bool IsValid { get; set; }
    }
    ```
    No Revit types. Pure POCO DTO per INFRA-07.

    **3. Create `Events/RevitEventBridge.cs`:**
    Per D-09 and D-10 -- single handler, enum dispatch, thread-safe:
    - Private fields: `_requestType` (volatile RevitRequestType), `_requestData` (volatile object), `_resultCallback` (Action&lt;object&gt;), `_lock` (object)
    - `MakeRequest(RevitRequestType type, object data, Action<object> callback)`: acquires lock, sets fields, then calls `App.RevitEvent.Raise()`. Per D-11 evaluation: do NOT use ExternalEvent&lt;T&gt; (it does not fit enum dispatch -- see RESEARCH.md lines 248-253).
    - `ProcessRequest(UIApplication uiApp)`: acquires lock, reads fields, resets _requestType to None. Switch on type:
      - `GetDocumentInfo`: reads `uiApp.ActiveUIDocument?.Document` for Title and PathName, creates RevitDocInfoDto.
    - Catch exceptions, pass Exception object back via callback.
    - Marshal callback to UI thread via `System.Windows.Application.Current.Dispatcher.Invoke(() => callback(result))`.
    - Use `using Autodesk.Revit.UI;` -- this file IS the Revit boundary layer (it is allowed to import Revit types, unlike ViewModels).

    **4. Create `App.cs`:**
    Per D-12, inherit from Nice3point.Revit.Toolkit `ExternalApplication`:
    - Static properties: `RevitEvent` (Nice3point.Revit.Toolkit.ExternalEvent), `EventBridge` (RevitEventBridge), `MainWindow` (MainWindow, nullable)
    - `OnStartup()`:
      1. Create EventBridge = new RevitEventBridge()
      2. Create RevitEvent = new ExternalEvent(application => EventBridge.ProcessRequest(application))
      3. Create ribbon panel: `Application.CreatePanel("Olympe", "OlympeMaterialManager")`
      4. Add push button: `panel.AddPushButton<ShowWindowCommand>("Materiaux")` -- French label per UI-04. Skip icon images for now (no Resources/Icons yet) -- Nice3point allows button without image.
    - `OnShutdown()`: close MainWindow, dispose RevitEvent.

    **5. Create `Commands/ShowWindowCommand.cs`:**
    Per D-13, inherit from Nice3point.Revit.Toolkit `ExternalCommand`:
    - `[Transaction(TransactionMode.Manual)]` attribute
    - `Execute()` method:
      1. If `App.MainWindow == null`:
         - Create MainWindowViewModel passing App.EventBridge
         - Create new MainWindow(), set DataContext = vm
         - Set `new WindowInteropHelper(App.MainWindow).Owner = Application.MainWindowHandle` (Revit as owner per RESEARCH.md pattern)
         - Subscribe to `App.MainWindow.Closing += (s, e) => { e.Cancel = true; App.MainWindow.Hide(); }` per D-13
      2. `App.MainWindow.Show()` then `App.MainWindow.Activate()`

    **6. Create `Helpers/ElementIdHelper.cs`:**
    Per D-04, safe accessor for ElementId.Value (long):
    ```
    using Autodesk.Revit.DB;
    namespace Olympe.MaterialManager.Helpers;
    public static class ElementIdHelper
    {
        public static long GetValue(ElementId id) => id.Value;
        public static ElementId FromValue(long value) => new ElementId(value);
    }
    ```
    This is a Revit-layer file (allowed to import Revit types). It centralizes D-04 convention.

    **7. Modify `ViewModels/MainWindowViewModel.cs`:**
    Update the existing file from Plan 02:
    - Add a `private readonly RevitEventBridge _eventBridge;` field (import `Olympe.MaterialManager.Events`, NOT Autodesk.Revit)
    - Update constructor to accept `RevitEventBridge eventBridge` parameter, assign to `_eventBridge`
    - Add `[RelayCommand] private void RafraichirDocument()` method that calls:
      ```
      _eventBridge.MakeRequest(
          RevitRequestType.GetDocumentInfo,
          null,
          result =>
          {
              if (result is RevitDocInfoDto info)
                  DocumentInfo = info.IsValid ? $"Document : {info.Title}" : "Aucun document ouvert";
          });
      ```
      Import `Olympe.MaterialManager.Models` for RevitDocInfoDto.
    - Add a parameterless constructor `public MainWindowViewModel() : this(null!) { }` for WPF designer support (or use design-time check).
    - CRITICAL: MainWindowViewModel.cs must NOT contain `using Autodesk.Revit` anywhere (per INFRA-07). RevitEventBridge is in Olympe.MaterialManager.Events namespace -- it is our code, not Revit API.

    **8. Add a "Rafraichir" button to MainWindow.xaml:**

    - A Button: Content="Rafraichir le document", Command="{Binding RafraichirDocumentCommand}" (French per UI-04)
    - A TextBlock: Text="{Binding DocumentInfo}" -- shows the round-trip result
    This proves the ExternalEvent pipeline visually. Place it above the 3-column grid (add a Row to the root Grid: Row 0 = header bar, Row 1 = 3-column panels).
