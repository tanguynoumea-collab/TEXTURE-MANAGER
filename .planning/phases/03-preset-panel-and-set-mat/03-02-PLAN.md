    - `[RelayCommand] AjouterMateriau()` per D-10: Calls `_eventBridge.MakeRequest(RevitRequestType.GetAllMaterials, null, callback)`. In callback: if result is `List<PresetMaterialDto>`, open an AddMaterialDialog (modal Window) passing the materials list and the current PresetGroups.       For the dialog interaction: create an instance of AddMaterialDialog, set its DataContext with the materials and groups, call ShowDialog(). Read back the user's selection. This is standard WPF modal pattern -- no MVVM violation since the dialog is a UI concern, and the ViewModel merely opens it and reads the result.

    - `[RelayCommand] DupliquerMateriau(PresetMaterialDto material)` per D-12, D-13: Takes material as CommandParameter. Call `_eventBridge.MakeRequest(RevitRequestType.DuplicateMaterial, new DuplicateMaterialRequestDto { MaterialIdValue = material.MaterialElementIdValue }, callback)`. In callback: if result is PresetMaterialDto newMat, find the group containing the original material, add newMat to same group. Call AutoSave(). If result is Exception, show error via StatusMessage.

    - `[RelayCommand] SupprimerMateriau(PresetMaterialDto material)` per D-12: Takes material as CommandParameter. Find the group containing the material, remove it from Materials collection. Call AutoSave().

    - `[RelayCommand] TreeViewSelectionChanged(object? param)`: Set SelectedPresetMaterial if param is PresetMaterialDto, null otherwise (group selected or deselected). Also send a lightweight message or raise PropertyChanged so MainWindowViewModel can refresh CanExecute (see Pitfall 5 from RESEARCH).

    **Private methods:**

    - `LoadPresets()`: Read stored path via `_presetService.GetStoredPresetPath()`. If path exists and file exists, load via `_presetService.Load(path)`. If path is null or file missing, use `PresetService.GetDefaultCollection()` and set _presetFilePath to null (will prompt on first save). Set PresetGroups = collection.Groups. Set _collection = collection.

    - `AutoSave()` per D-07: If `_presetFilePath` is null, call `DialogService.ShowFolderBrowser("Choisir le dossier des presets")`. If user picks a folder, set `_presetFilePath = Path.Combine(folder, "olympe-presets.json")` and call `_presetService.StorePresetPath(_presetFilePath)`. If user cancels, return without saving (presets stay in memory). Then call `_presetService.Save(_collection, _presetFilePath)`.
