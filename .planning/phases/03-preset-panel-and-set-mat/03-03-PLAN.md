    **OnSetMatResult callback per D-18, D-19, D-25:**

    ```csharp
    private void OnSetMatResult(object? result)
    {
        IsSetMatBusy = false;

        if (result is Exception ex)
        {
            // D-18: Error with French message
            SetMatStatusText = $"Erreur : {ex.Message}";
            System.Windows.MessageBox.Show(
                $"Erreur lors de l'application du materiau :\n{ex.Message}",
                "Olympe MaterialManager",
                System.Windows.MessageBoxButton.OK,
                System.Windows.MessageBoxImage.Error);
        }
        else
        {
            // D-19: Success feedback
            SetMatStatusText = "Materiau applique !";
            // D-25: Refresh center panel to show updated material names
            WeakReferenceMessenger.Default.Send(
                new RefreshLayersMessage(CenterPanelVM.CurrentTypeIdValue));
            // Clear feedback after 2 seconds
            StartFeedbackTimer();
        }

        AppliquerMateriauCommand.NotifyCanExecuteChanged();
    }
    ```

    **StartFeedbackTimer() per D-19:**

    Use `System.Windows.Threading.DispatcherTimer` with 2-second interval. On tick: set `SetMatStatusText = string.Empty` and stop the timer. Lightweight feedback per Research recommendation.
