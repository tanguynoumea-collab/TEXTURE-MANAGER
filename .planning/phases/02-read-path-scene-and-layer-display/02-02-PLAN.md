- Set `IsLoadingFamilies = true`
- `_eventBridge?.MakeRequest(RevitRequestType.GetFamilyList, null, result => { ... })`

- On exception: set `ErrorMessage = "Erreur : " + ex.Message`, set `IsLoadingFamilies = false`.

- Set `SelectedType = null`

- If value == null, clear FamilyTypes, return
- Set `IsLoadingTypes = true`
